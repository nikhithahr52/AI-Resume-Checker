**Live Demo:** https://ai-resume-checker-2gtcczxho8tjwcavtgiskg.streamlit.app

AI tool that analyzes your resume for Data Analyst jobs and gives a fit score.

### Features
- Upload PDF Resume
- Calculates Fit Score %
- Checks for Python, SQL, Excel, Power BI skills

### Tech Used
Python, Streamlit, PyPDF2

### How to Run
pip install -r requirements.txt
streamlit run app.py
